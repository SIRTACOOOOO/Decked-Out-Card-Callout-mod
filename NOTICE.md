## Credits
This mod is based on **Decked Out OBS** by **Meza** (https://github.com/meza/decked-out-obs),
which was released under the GNU LGPL-3.0. Meza created the original card detection,
settings and card artwork pipeline; this version adds an in-game overlay (instead of an OBS
browser source), a Mod Menu settings screen, support for Minecraft 1.21.11, manual dungeon
positioning, sound-based detection, and removes the OBS web server and its port option.

The LGPL-3.0 permits conveying a modified work under the GPL-3.0, which is what is done here.
Card artwork originates from the original Decked Out OBS mod.
